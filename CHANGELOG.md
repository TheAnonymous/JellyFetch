# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-04-12
### Added
- Initial release of JellyFetch.
- Download videos from various web sources using `yt-dlp`.
- Simple web interface for submitting video URLs.
- Configurable download directory.
- Configurable path to `yt-dlp` executable.
- Authentication using Jellyfin API Keys for download requests.
- Background processing of downloads.
